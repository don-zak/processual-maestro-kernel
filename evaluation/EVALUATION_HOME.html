Guided review flow

  1. Confirm runtime health.
  2. Open the Console and identify the workflow / task execution surface.
  3. Observe how access, entitlement, quota and runtime controls constrain execution.
  4. Open the recorded governance evidence and inspect rank, reward, policy and action semantics.
  5. Open Admin to review operational controls, auditability and commercial/runtime separation.
  6. Use API Docs only when deeper technical verification is useful.

Local access

Run .\SHOW-EVALUATION-ACCESS.ps1 to view the local evaluator identity. Add -ShowSecrets only when you need to copy the generated local API key or admin password.

Run .\RUN-GUIDED-DEMO.ps1 after startup to open the reviewer home and recorded governance evidence together.

Evaluation boundary. This package contains no production secrets, excludes private CGT implementation code, disables real billing and Tunisia top-up, and disables external LLM execution by default. Recorded governance evidence is replayed from a previously verified local run and is not a live provider call or Production evidence.

Recommended demonstration

Use the Enterprise Incident / Ticket Governance scenario described in GUIDED-DEMO.md. The narrative is: controlled input → authority and quota checks → governed processing → recorded governance decision/evidence → human review → audit.
