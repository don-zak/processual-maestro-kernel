# Maestro Reference Workloads R1

The executable catalog contains exactly 36 workloads across automation, integrations, documents, data, verification, supervision, research/mixed work, failures, retries, duplicates, cancellations, and custom workloads.

The Python catalog is the canonical machine-readable source for this bundle:

`processual_api/billing/maestro_reference_workloads.py`

No workload in this catalog authorizes customer billing. Expected values are hypotheses used to test consistency, monotonicity, failure safety, and later cost calibration.
